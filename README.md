# SecretGear — лаунчер + модуль Minecraft Dungeons

`Launcher.exe` — лаунчер **SecretGear** с библиотекой игр в тёмном стиле.
Обложки игр лаунчер сам скачивает с серверов Steam (Steam CDN) и хранит в `%APPDATA%\MCDLoader\cache\art`.
Без интернета вместо обложки рисуется фон.

Что есть в лаунчере:
- **Запуск:** окно без системной рамки, экран загрузки с «жидким» логотипом.
- **Лаунчер:** «Главная» с каруселью игр и новостями, «Библиотека» с карточками игр и «Система» с проверками.
- **Модуль игры:** выбираете игру в библиотеке, показывается экран загрузки и открывается её модуль. Кнопка «← Библиотека» возвращает назад.

Сейчас готов модуль **Minecraft Dungeons**. RV There Yet? стоит в библиотеке карточкой «Скоро».
Новая игра добавляется записью в список `GAMES` в `mcd_loader/hub.py` и своим модулем.

Модуль Minecraft Dungeons — это редактор сохранений поверх запущенной игры по горячей клавише (**F8**).
Он умеет всё то же, что и [MCDSaveEdit](https://github.com/CutFlame/MCDSaveEdit), а также показывает все предметы с иконками и включает ходьбу на WASD.

## Возможности

**Интерфейс** — тёмно-синяя тема с боковым меню (Персонаж, Инвентарь, Моды, JSON, Настройки), карточки с переключателями,
иконки предметов и зачарований.

**Персонаж**
- уровень и опыт (XP), связанные между собой;
- изумруды, золото, око Эндера и кнопка «Открыть портал» (как «Unlock Portal» в MCDSaveEdit);
- открытая сложность (По умолчанию / Приключение / Апокалипсис) и уровень угрозы (Threat 1–7);
- сводка: сила персонажа и свободные очки зачарований (формулы как в MCDSaveEdit);
- **очки зачарований:** впишите, сколько свободных очков нужно (например, 1000). Отдельного числа очков в сохранении нет, игра считает «уровень − 1 − потраченное», поэтому есть два способа:
  - «Через уровень» — надёжный: уровень поднимается ровно на нужное количество очков, в игре будет виден новый уровень;
  - «Бонус без уровня» — экспериментальный: в пустую ячейку зачарования записываются отрицательные `investedPoints`. Сработает, только если игра считает потраченное по этим числам. Проверьте в игре, бэкап делается автоматически.
- быстрые действия: 999 999 изумрудов и золота, открыть всё, 100-й уровень.

**Все предметы игры с иконками**
- загрузчик читает файлы установленной игры (`Dungeons\Content\Paks`), так же как MCDSaveEdit;
- полный список оружия, брони, артефактов, зачарований и свойств брони вместе с иконками и русскими названиями из игры;
- **«Добавить предмет…»** открывает каталог всех предметов игры:
  - поиск по названию или ID, фильтр по типу;
  - добавить в инвентарь или в сундук, сразу надеть;
  - выбрать уровень и количество;
- зачарования выбираются по иконке и названию, с описанием; сначала показываются подходящие для слота.

**Инвентарь и сундук**
- список всех предметов с иконками, фильтр: надетые, инвентарь, сундук;
- у предмета редактируются:
  - тип (ID);
  - уровень силы;
  - редкость;
  - слот экипировки;
  - флаги «улучшен», «подарок» и «новый»;
- 3 слота зачарований по 3 варианта; уровень 0–3, `investedPoints` пересчитывается автоматически;
- позолоченное (незеритовое) зачарование;
- свойства брони;
- добавить, дублировать и удалить предмет, переложить его между сундуком и инвентарём;
- массовые действия: уровень всех предметов и «Выбранные чары до 3». Эта кнопка поднимает до 3 только уже выбранные зачарования и не трогает невыбранные варианты;
- «Снять все чары с предмета» — отменить выбор всех зачарований предмета (предложенные варианты остаются).

**JSON** — полный текст сохранения для ручной правки любых полей.

**Сервис**
- автоматический бэкап перед каждым применением;
- восстановление из бэкапа;
- экспорт и импорт JSON;
- запуск игры: лаунчер, Steam или Xbox;
- CLI для расшифровки и шифрования файлов.

**Мод: ходьба на WASD**
- в разделе «Моды» включите «Ходьба на WASD»: клавиши двигают персонажа, Shift — шагом, стрелки тоже работают;
- мышь продолжает атаковать и целиться как обычно.

## Как применять изменения в игре

Игра держит персонажа в памяти и записывает его на диск при выходе в главное меню.
Поэтому порядок такой:

1. В игре выйдите из миссии или лагеря в **главное меню**.
2. Нажмите **F8**. Оверлей перечитает свежее сохранение, отредактируйте его.
3. Нажмите **«Применить в игре»** (Ctrl+S).
4. **Выберите персонажа заново**: игра загрузит изменённый файл.

Загрузчик следит за файлом сохранения. Если файл перезапишет игра, данные в окне перезагрузятся сами.
Если у вас есть непримененные правки, появится предупреждение.

> Оверлей виден поверх игры в режиме **«В окне»** или **«Полноэкранный в окне»**.
> В эксклюзивном полноэкранном режиме Windows свернёт игру при показе окна.
> Esc прячет оверлей, F8 показывает его снова. Клавишу можно сменить в настройках.

⚠️ Редактируйте только своих персонажей в одиночной игре и делайте бэкапы.
Неверный ID предмета или зачарования может сделать сохранение нечитаемым для игры.
В таком случае восстановите файл кнопкой «Восстановить из бэкапа».

## Файлы игры и иконки

Папка `Paks` находится автоматически для лаунчера Minecraft, Steam и Xbox. Если не нашлась, укажите её в «Настройках».
Обычно это `…\Dungeons\Content\Paks` рядом с `Dungeons.exe`.

Файлы игры зашифрованы. Загрузчик перебирает общеизвестные ключи для версий 1.17.0.0, 1.9.1.0, 1.8.x и более ранних.
Если ни один не подошёл, впишите ключ своей версии в поле «AES-ключ pak».
Каталог и иконки кэшируются в `%APPDATA%\MCDLoader\cache`. Первый запуск дольше, потом всё открывается сразу.

Без файлов игры редактор тоже работает. Тогда в каталоге только предметы, которые уже есть в сохранении (`itemsFound`), и без иконок.

Проверка из консоли:
```bat
python -m mcd_loader items --icons
```
Команда выведет все найденные предметы и зачарования и посчитает, сколько иконок удалось извлечь.

## WASD: как это работает

Игра на ПК умеет ходить только мышью или геймпадом. Мод создаёт **виртуальный геймпад Xbox 360**.
Пока активно окно игры, W/A/S/D двигают его левый стик. В других окнах клавиши ничего не делают.

- Нужен драйвер **ViGEmBus**. Он ставится вместе с пакетом `vgamepad` при `pip install -r requirements.txt`.
  Если не поставился, скачайте установщик ViGEmBus отдельно и перезапустите загрузчик.
- Мод работает **в любом мире, в том числе у друга**. Управление обрабатывается на вашем ПК, и хосту ничего ставить не нужно.
- Другу WASD нужно включить у себя: запустить загрузчик на своём ПК и поставить ту же галочку.
- Если какая-то из клавиш W/A/S/D занята в настройках управления игры, переназначьте это действие в игре.
- Если в одиночной игре виртуальный геймпад подключит второго игрока (локальный кооператив), не нажимайте «присоединиться».
  Виртуальный геймпад двигает только стик и кнопки не нажимает.

## Скачать

Готовый **Launcher.exe** лежит в [Releases → latest](https://github.com/masterRaizer/Test/releases/tag/latest).
Он собирается автоматически (GitHub Actions, `.github/workflows/build-exe.yml`) после каждого изменения.
Python не нужен.

При запуске показывается заставка с загрузкой, потом плавно открывается окно. F8 плавно скрывает и показывает его.
Если файлы игры не нашлись, сверху появится жёлтое предупреждение с кнопкой «Указать папку игры…».
Можно выбрать любую папку, где установлена игра: `Paks` внутри найдётся сам.
Подробный лог: `%APPDATA%\MCDLoader\loader.log`.

Файл не подписан, поэтому Windows может показать предупреждение SmartScreen. Чтобы запустить, нажмите «Подробнее» → «Выполнить в любом случае».
Драйвер для WASD (ViGEmBus) встроен в exe. Загрузчик сам предложит его установить при первом включении мода.

## Запуск из исходников

Нужны Windows и Python 3.10+ с компонентом tcl/tk (стандартный установщик с python.org ставит его по умолчанию).

```bat
run.bat            :: запустить оверлей
run.bat --launch   :: запустить оверлей и игру
build.bat          :: собрать один файл dist\Launcher.exe
```

Или вручную:

```bat
pip install -r requirements.txt
python -m mcd_loader                 :: оверлей
python -m mcd_loader list            :: найденные сохранения
python -m mcd_loader decrypt a.dat a.json
python -m mcd_loader encrypt a.json a.dat
```

Сохранения ищутся в `%USERPROFILE%\Saved Games\Mojang Studios\Dungeons\<id>\Characters\*.dat`
и в папке версии из Microsoft Store. Любой другой файл можно открыть кнопкой «Открыть .dat…».
Настройки и бэкапы лежат в `%APPDATA%\MCDLoader`.

## ID предметов и зачарований

Выпадающие списки собираются из нескольких источников:
- поля `itemsFound` сохранения (все предметы, которые персонаж когда-либо находил);
- предметов в инвентаре;
- известных ID зачарований из MCDSaveEdit.

В поля можно вписать любой ID вручную. Имена уникальных предметов строятся по схеме `<База>_Unique1`, например `Chainsword_Unique1`.
Пустой вариант зачарования обозначается `Unset`.

## Формат сохранения

`D001` + 4 нулевых байта, затем JSON, зашифрованный AES‑256‑ECB с нулевым дополнением.
Ключ общеизвестен и взят из [DungeonTools](https://github.com/CutFlame/DungeonTools).
Реализация находится в `mcd_loader/crypto.py`.
Тест проверяет, что расшифровка и повторное шифрование реального файла дают побайтово идентичный результат.

## Разработка

```bash
python -m unittest discover -s tests -t .
```

Структура:
- `mcd_loader/crypto.py` — шифрование `.dat`;
- `mcd_loader/gamedata.py` — константы и формулы игры;
- `mcd_loader/savefile.py` — модель сохранения и операции над предметами;
- `mcd_loader/game.py` — конфиг, поиск и запуск игры, горячая клавиша;
- `mcd_loader/ue4pak.py` — чтение `.pak` (индекс, AES, zlib), локализации `.locres` и текстур Texture2D;
- `mcd_loader/catalog.py` — каталог предметов, зачарований, названий и иконок с кэшем;
- `mcd_loader/pickers.py` — окна выбора предметов и зачарований с иконками;
- `mcd_loader/wasd.py` — мод WASD через виртуальный геймпад;
- `mcd_loader/hub.py` — лаунчер SecretGear: главная, библиотека игр, система, переход в модуль;
- `mcd_loader/art.py` — загрузка и кэш обложек игр со Steam;
- `mcd_loader/shell.py` — окно без рамки, пункты меню, экран загрузки, карусель, кнопки;
- `mcd_loader/overlay.py` — модуль Minecraft Dungeons (редактор).

Тестовый файл `tests/data/Blank.dat` взят из MCDSaveEdit (MIT).
Проект не связан с Mojang Studios и Microsoft.
