# MCD Loader — внутриигровой редактор для Minecraft Dungeons

Загрузчик открывает редактор сохранений поверх запущенной игры по горячей клавише (**F8**).
Он умеет всё то же, что и [MCDSaveEdit](https://github.com/CutFlame/MCDSaveEdit): уровень, валюта, предметы и зачарования.
Изменения можно вносить прямо во время игры и применять кнопкой, не выходя из неё.

## Возможности

**Персонаж**
- уровень и опыт (XP), связанные между собой;
- изумруды, золото, око Эндера;
- открытая сложность (По умолчанию / Приключение / Апокалипсис) и уровень угрозы (Threat 1–7);
- сводка: сила персонажа и свободные очки зачарований (формулы как в MCDSaveEdit);
- быстрые действия: 999 999 изумрудов и золота, открыть всё, 100-й уровень.

**Инвентарь и сундук**
- список всех предметов с фильтром: надетые, инвентарь, сундук;
- у предмета редактируются:
  - тип (ID);
  - уровень силы;
  - редкость;
  - слот экипировки;
  - флаги «улучшен», «подарок» и «новый»;
- 3 слота зачарований по 3 варианта; уровень 0–3, `investedPoints` пересчитывается автоматически;
- позолоченное (незеритовое) зачарование;
- свойства брони;
- добавить, дублировать и удалить предмет, переложить его между сундуком и инвентарём;
- массовые действия: уровень всех предметов, все зачарования на уровень 3.

**JSON** — полный текст сохранения для ручной правки любых полей.

**Сервис**
- автоматический бэкап перед каждым применением;
- восстановление из бэкапа;
- экспорт и импорт JSON;
- запуск игры: лаунчер, Steam или Xbox;
- CLI для расшифровки и шифрования файлов.

## Как применять изменения в игре

Игра держит персонажа в памяти и записывает его на диск при выходе в главное меню.
Поэтому порядок такой:

1. В игре выйдите из миссии или лагеря в **главное меню**.
2. Нажмите **F8**. Оверлей перечитает свежее сохранение, отредактируйте его.
3. Нажмите **«Применить в игре»** (Ctrl+S).
4. **Выберите персонажа заново**: игра загрузит изменённый файл.

Загрузчик следит за файлом сохранения. Если файл перезапишет игра, данные в окне перезагрузятся сами.
Если у вас есть непримененные правки, появится предупреждение.

> Оверлей виден поверх игры в режиме **«В окне»** или **«Полноэкранный в окне»**.
> В эксклюзивном полноэкранном режиме Windows свернёт игру при показе окна.
> Esc прячет оверлей, F8 показывает его снова. Клавишу можно сменить в настройках.

⚠️ Редактируйте только своих персонажей в одиночной игре и делайте бэкапы.
Неверный ID предмета или зачарования может сделать сохранение нечитаемым для игры.
В таком случае восстановите файл кнопкой «Восстановить из бэкапа».

## Запуск

Нужны Windows и Python 3.10+ с установленной галочкой tcl/tk (стандартный установщик с python.org).

```bat
run.bat            :: запустить оверлей
run.bat --launch   :: запустить оверлей и игру
build.bat          :: собрать один файл dist\MCDLoader.exe
```

Или вручную:

```bat
pip install -r requirements.txt
python -m mcd_loader                 :: оверлей
python -m mcd_loader list            :: найденные сохранения
python -m mcd_loader decrypt a.dat a.json
python -m mcd_loader encrypt a.json a.dat
```

Сохранения ищутся в `%USERPROFILE%\Saved Games\Mojang Studios\Dungeons\<id>\Characters\*.dat`
и в папке версии из Microsoft Store. Любой другой файл можно открыть кнопкой «Открыть .dat…».
Настройки и бэкапы лежат в `%APPDATA%\MCDLoader`.

## ID предметов и зачарований

Выпадающие списки собираются из нескольких источников:
- поля `itemsFound` сохранения (все предметы, которые персонаж когда-либо находил);
- предметов в инвентаре;
- известных ID зачарований из MCDSaveEdit.

В поля можно вписать любой ID вручную. Имена уникальных предметов строятся по схеме `<База>_Unique1`, например `Chainsword_Unique1`.
Пустой вариант зачарования обозначается `Unset`.

## Формат сохранения

`D001` + 4 нулевых байта, затем JSON, зашифрованный AES‑256‑ECB с нулевым дополнением.
Ключ общеизвестен и взят из [DungeonTools](https://github.com/CutFlame/DungeonTools).
Реализация находится в `mcd_loader/crypto.py`.
Тест проверяет, что расшифровка и повторное шифрование реального файла дают побайтово идентичный результат.

## Разработка

```bash
python -m unittest discover -s tests -t .
```

Структура:
- `mcd_loader/crypto.py` — шифрование `.dat`;
- `mcd_loader/gamedata.py` — константы и формулы игры;
- `mcd_loader/savefile.py` — модель сохранения и операции над предметами;
- `mcd_loader/game.py` — конфиг, поиск и запуск игры, горячая клавиша;
- `mcd_loader/overlay.py` — интерфейс оверлея.

Тестовый файл `tests/data/Blank.dat` взят из MCDSaveEdit (MIT).
